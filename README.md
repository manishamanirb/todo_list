To-Do List CLI Application Using Python

Project Description  :

This project is a command-line To-Do List application developed using Python as part of the CodeOrbit Tech Python Programming Internship.

It allows users to manage their daily tasks through a simple menu.

Features :

- Add new tasks
- View tasks in a numbered list
- Remove tasks by selecting their numbers
- Handle invalid task numbers
- Prevent empty tasks from being added

Technologies Used :

- Python 3
- Lists
- Functions
- Visual Studio Code

How to Run :

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Run "todo_list.py".
5. Choose an option from the menu to add, view, or remove tasks.

Concepts Used:

- Lists
- Functions
- Loops
- Conditional statements
- Exception handling
- User input and output
